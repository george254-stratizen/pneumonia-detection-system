# Pneumonia Detection System

AI-powered web application for pneumonia detection from chest X-rays, built for healthcare providers in resource-constrained facilities.

## Tech stack
Python, PyTorch (ResNet50), OpenCV (CLAHE), Streamlit, SQLite, PyTest

## Setup
1. python -m venv venv
2. venv\Scripts\Activate.ps1
3. pip install -r requirements.txt
4. streamlit run app.py
